# services/normalize

Нормализация входного фото перед поиском (ТЗ: «поработайте с нормализацией — заметно
улучшает F1»).

Задачи:
- EXIF-ориентация, ресайз, денойз, баланс белого.
- Детекция этикетки/бутылки (D-FINE / RT-DETRv4 / RF-DETR, Apache-2.0).
- Выпрямление перспективы (гомография), кроп этикетки.
- TTA: несколько кропов/масштабов.

Интерфейс (план): `POST /normalize` (image) → список нормализованных изображений.

Статус: скелет (M0), реализация — M1.
