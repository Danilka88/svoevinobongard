# Итоговые метрики

Все цифры получены командами из этого документа на актуальном proxy-наборе
(200 сэмплов, seed 42, full-frame вход, нормализация + геоверификация).
Перепроверить одной командой: `make gate`.

## Что включено по умолчанию

| режим | значение | почему так |
|---|---|---|
| `TEXT_FUSION_MODE` | `conditional` | срабатывает только на near-dup пару в визуальном top-2: 32/150 срабатываний, 2 улучшения ранга, **0 ухудшений** и 0 вмешательств на 118 не-триггерных запросах |
| `OCR_ENGINE` | `rapidocr` (пусто = дефолт) | слияние `fusion` читает лучше (год 1.0 на синтетике, winery 0.4 против 0.15 на эталонах), но на proxy-ранжировании прироста нет (±1 запрос), а latency вдвое выше — включается осознанно |
| `VLM_FALLBACK_ENABLED` | `0` (выключен) | локальный VLM отвечает 20–34 с против SLA 3 с; офлайн-обогащение делается отдельно моделью 26b |
| `NORMALIZE_CROP` | `0` | кроп этикетки ломает овальные и цилиндрические этикетки, блики и ракурсы; работает полный кадр + P&S |
| `PAS_TILES` / `PAS_TILES_UNCERTAIN` | 4 / 6 | покрытие всего кадра без знания положения этикетки |
| `GEO_WEIGHT` | 3.0 | геоверификация ORB+RANSAC разводит near-duplicates |

## Честные ограничения

1. **Полевых фото нет** (удалены в C-011 по требованию чистоты данных) — все метрики получены на
   эталонах каталога и синтетической аугментации. Полевое качество не измерено и может отличаться.
2. **Узкое место — сторона запроса:** год присутствует в OCR-тексте полевого запроса лишь у 6 из 150
   кадров, сладость — у 0 из 150. Поэтому обогащение каталога (26b, 137 годов) не даёт прироста в
   conditional-фьюжне: сигнал нужен с обеих сторон.
3. **PaddleOCR-VL** (Apache-2.0) читает лучше всех (`Коммуналка | Пино Нуар | Рислинг | 2022 сухое`
   без ошибок), но **~228 с на кадр** на MPS — офлайн-инструмент, не онлайн.
4. **Кириллический OCR** (PP-OCRv5 mobile) читает слова, но склеивает цифры с текстом
   («2022сухое»), поэтому год из него не извлекается; server-варианта cyrillic rec не существует.
5. `confidence_temperature` и текстовые бонусы не перекалиброваны: выигрыш альтернатив в пределах шума
   на доступном стенде.
6. Метрики пересчитываются только на macOS arm64 (MPS); на другой платформе latency будет иной.
