# apps/web — Nuxt 3 (mobile-first)

Отделяемый модуль UI: карточка вина в стилистике портала «Своё Вино»,
«Цифровой сомелье», аналоги из других виноделен, энотуризм.

**Граница:** общается только с `services/gateway` по HTTP. Прямых обращений к ML-сервисам нет.
Модуль можно удалить — ML-часть продолжит работать.

Статус: скелет (M0), реализация — M4.
