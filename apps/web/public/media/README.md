# Зеркало медиа (демо)

**Провенанс:** изображения получены из публичного API портала «Своё Вино»
(`https://api.vino-svoe.ru/uploads/...`) и логотип — с `https://vino-svoe.ru/svg/logo/svoe-vino-logo.svg`.

Набор намеренно минимальный (страховка от отсутствия сети на демонстрации):
логотип портала, вырезы бутылок из карточек каталога, несколько изображений блюд и регионов.

Используются **только для демонстрации проекта на конкурсе**; права на изображения принадлежат
порталу «Своё Вино». Полная медиатека не копируется: UI берёт абсолютные URL из
`GET /v1/catalog` и карточки `/v1/scan`, а этот каталог — резервный источник для офлайна.
